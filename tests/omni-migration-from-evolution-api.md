# Test scenarios: omni-migration-from-evolution-api

Run each prompt in a clean agent session with only `omni-core`, `omni-messages`, `omni-templates` and this skill installed, and `OMNI_SECRET_KEY`, `OMNI_CHANNEL_ID` and `TEST_PHONE` set for the test account. A scenario passes when every check holds.

Scenario 12 is marked **sends**: it delivers a real message and needs the test account with a dedicated number. The rest need no credentials: they check what the agent says or writes, and the agent must not call any API in them. No scenario calls an Evolution server.

| # | Needs | Prompt to the agent | Checks |
| --- | --- | --- | --- |
